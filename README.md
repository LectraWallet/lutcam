# LUT Cam

A clean pro photo camera for iPhone. Manual ISO, shutter, white balance and
focus — each with its own Auto switch — plus import-your-own .cube LUTs with a
strength slider, applied when you save.

- Photo only, no video. Back camera.
- Every slider is clamped to what the device actually supports, and every
  camera change is guarded — no crashes from out-of-range values.
- LUTs you import are copied into the app and stay there.
- Liquid Glass look via system materials (renders as glass on iOS 26+).

Built with GitHub Actions (unsigned IPA, sideload with Sideloadly).
Bundle ID: `com.lutcam.app`
